# Jardim dos Baobás

Bem-vindo ao repositório do site institucional do Jardim dos Baobás, uma escola infantil com proposta pedagógica inspirada na educação Waldorf, que valoriza a infância, a natureza, a criatividade e o desenvolvimento integral da criança.

## Sobre a instituição

O Jardim dos Baobás nasceu para acolher crianças em um ambiente seguro, acolhedor e cheio de significado. A proposta da escola é criar experiências que respeitem o ritmo da infância, conectem as crianças ao mundo natural e favoreçam o despertar da curiosidade, da imaginação e do pertencimento.

O site foi desenvolvido para transmitir essa identidade com uma linguagem visual moderna, acolhedora e clara, reforçando a presença da escola e a comunicação com famílias, visitantes e interessados em conhecer a proposta pedagógica.

## Objetivo do projeto

Este projeto tem como finalidade:

- apresentar a escola e sua proposta pedagógica;
- reforçar os valores e a identidade da instituição;
- facilitar o contato com a comunidade;
- destacar o ambiente escolar e a experiência de infância oferecida;
- apresentar a localização e os canais de atendimento.

## Estrutura da experiência

A página foi organizada em seções que destacam a essência da escola, como:

- apresentação inicial e identidade visual;
- proposta pedagógica;
- espaço escolar e ambiente de aprendizagem;
- valores e princípios da instituição;
- galeria de imagens;
- contato e localização.

## Como executar localmente

### Pré-requisitos

- Node.js 20 ou superior
- pnpm

### Instalação

```bash
git clone https://github.com/jefersonpmatos/jardim-dos-baobas.git
cd jardim-dos-baobas
pnpm install
```

### Desenvolvimento

```bash
pnpm dev
```

O projeto estará disponível em `http://localhost:3000`.

### Build para produção

```bash
pnpm build
```

### Execução em produção

```bash
pnpm start
```

## Scripts do projeto

```bash
pnpm dev       # inicia o servidor em ambiente de desenvolvimento
pnpm build     # gera a versão de produção
pnpm start     # executa a aplicação em produção
pnpm lint      # valida o código com ESLint
pnpm typecheck # verifica tipos do TypeScript
pnpm format    # formata arquivos TS/TSX
```
